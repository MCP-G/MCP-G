### 🛠️ What I work on

- 🔌 **API integrations.** Getting orders, stock and accounts to flow between platforms that were never designed to talk to each other.
- 🤖 **AI agent tooling.** MCP servers, guard-rails and permission models, so agents can get real work done and know when to hand over to a human.
- ⚡ **Serverless at the edge.** Small, fast workers with webhooks, scheduled jobs and OAuth flows. No servers to babysit.
- 🎮 **Side quests.** Game prototypes and generative audio, mostly when nobody's looking.
